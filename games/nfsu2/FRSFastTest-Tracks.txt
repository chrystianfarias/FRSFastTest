FRSFastTest -- tracks for Mode=dev
==================================

Set these lines in FRSFastTest.ini -- for a drag race on City Drag #1:

    Mode=dev
    DevTrack=4201
    DevRaceType=4

DevRaceType has to be the track's own:

    0  circuit (also speedway, SUV races and free roam)
    1  sprint
    2  street X
    4  drag
    5  drift

The types below are the ones the career's own races use on each track; where
no career race uses a track, the type is guessed from its family and name,
and the line says so.

Mode=dev loads no save: a default car and no money. Races start with the
developers' defaults for opponents and laps, which cannot be set yet.
