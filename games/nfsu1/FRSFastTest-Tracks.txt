FRSFastTest -- tracks for Track=

Set the track's number in FRSFastTest.ini -- for a race on Stadium:

    Track=1002

Every race is a lap race with the default circuit gameplay: the quick start
cannot set the race type. Drag and drift tracks load and can be driven, but
without drag or drift gameplay (no automatic steering, the usual HUD).
A number not in this list is ignored: the default track is used.

Taken from the game's own track list (GLOBAL\GLOBALB.BUN, chunk 0x34201).
